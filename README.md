## General Info
Commute! is a browser based web application that helps commuters be on time. Users can save their
everyday routes, plan upcoming trips on a schedule, and get alerts about incidents that affect their routes.
The app has a light and a dark theme, which follows the device setting unless you pick one on the Themes page.
The map gives real directions between two places with travel time, distance and step by step instructions.

## Technologies
Technologies used for this project:
* HTML, CSS, JavaScript
* Bootstrap 5
* Firebase 8 (Authentication, Firestore)
* Leaflet + OpenStreetMap
* OSRM (directions) and Nominatim (address lookup), both via public OpenStreetMap services

## Running Locally
```
npm run dev
```
Then open http://localhost:8000, or `npm run dev -- --port 3000` for another port.

The site is plain HTML, CSS and JavaScript with no build step for development, so edits show up
on refresh. `scripts/dev-server.js` serves the source folders using Node's own http module, with
the same tidy paths Firebase serves in production, so `/routes` works here exactly as it does
live. It has no dependencies.

Firestore security rules live in `firestore.rules`. Each user can only read and write their own
data under `users/{uid}`. They are deployed separately from the site:
```
npx firebase deploy --only firestore:rules
```

## Deploying

The site is live at https://commuteapp.web.app on Firebase Hosting, which serves static files.
`npm run build:site` assembles them into `dist/`, and hosting rebuilds before every deploy.

Deploys go to the `commuteapp` site, set by `site` in `firebase.json`. The project also has its
original site at comp1800-5ce0f.web.app, which is no longer deployed to and will go out of date.

```
npm install
npx firebase login
npm run deploy
```

To check the built site through the real hosting config first:

```
npm install
npm run preview
```

`cleanUrls` in `firebase.json` is what keeps paths like `/routes` working without `.html`,
both in the emulator and in production.

### Rebuilding the map bundle
`public/js/webmap.js` is generated by browserify from the root `webmap.js`:
```
npm install
npm run build
```
The predefined routes and search helpers live separately in `public/js/mapRoutes.js`, so rebuilding
the bundle won't overwrite them.
