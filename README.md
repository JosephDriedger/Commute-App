## General Info
Commute! is a browser based web application that helps commuters be on time. Users can save their
everyday routes, plan upcoming trips on a schedule, and get alerts about incidents that affect their routes.
The app has a light and a dark theme, which follows the device setting unless you pick one on the Themes page.
The map gives real directions between two places with travel time, distance and step by step instructions.

## Technologies
Technologies used for this project:
* HTML, CSS, JavaScript
* Bootstrap 5
* Firebase 8 (Authentication, Firestore)
* Leaflet + OpenStreetMap
* OSRM (directions) and Nominatim (address lookup), both via public OpenStreetMap services
* Express (local server)

## Running Locally
```
npm install
npm run dev
```
Then open http://localhost:8000. `npm run dev` restarts the server when you change it;
`npm start` runs it without watching. Page, style and script changes just need a browser refresh.

Firestore security rules live in `firestore.rules`. Each user can only read and write their own
data under `users/{uid}`. Deploy the rules with:
```
firebase deploy --only firestore:rules
```

### Rebuilding the map bundle
`public/js/webmap.js` is generated by browserify from the root `webmap.js`:
```
npm install
npm run build
```
The predefined routes and search helpers live separately in `public/js/mapRoutes.js`, so rebuilding
the bundle won't overwrite them.
